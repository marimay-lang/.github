Marimay is a personal hobby project: a small programming language, its compiler
and runtime, and the programs I write while learning how everything fits
together. This organization keeps those experiments in one place.

The language uses **`.my`** source files and the **`mmay`** command. Its portable
**C17 bootstrap** feeds a bytecode VM and native compilation. The project is
experimental; APIs, syntax, and performance may change as I learn.

### Start with the language

[**marimay**](https://github.com/marimay-lang/marimay) contains the compiler,
runtime, specification, standard library, tests, and build instructions.
Source is public; this is a learning project, not a stable production release.
