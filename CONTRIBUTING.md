# Contributing to Marimay

Marimay is a personal open-source learning project. Small examples, clear bug
reports, and focused changes are welcome. Start with the README and contribution
instructions in the repository you are changing; compiler work also follows its
AGENTS.md, architecture contracts, and validation gates.

Describe the behavior you observed, the relevant commit and platform, and how
to reproduce it. Run the repository's documented checks and report their actual
results. Keep credentials, personal paths, local databases, and generated build
files out of commits and issue attachments.

Use English for repository documentation and issue discussion. Program examples
and Unicode test fixtures may intentionally contain other languages.
