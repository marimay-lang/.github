# Security policy

Marimay and its companion projects are experimental hobby software. No stable
production release or security support window is promised.

Please report security vulnerabilities privately through the
[main repository's private vulnerability reporting form](https://github.com/marimay-lang/marimay/security/advisories/new).
Include the affected repository, commit, minimal reproduction, and impact.
Do not publish credentials or exploit details in public issues.

If a credential is exposed, revoke or rotate it with its provider. Removing a
file or rewriting Git history does not invalidate an already exposed secret.
